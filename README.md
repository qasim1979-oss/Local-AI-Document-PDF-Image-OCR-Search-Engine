# Free Standalone Offline Local AI Document, PDF & Image OCR Search Engine (.exe)

A fast, lightweight, and 100% offline Windows desktop application designed to index massive local folders (98 GB+) containing PDFs, Word docs, text files, and images (JPG, PNG, GIF) using integrated Tesseract OCR, TF-IDF vector space matching, and **Smart Checkpoint Caching**.

## 🚀 v2.0.0 Performance Highlights
- **Optimized for Large Folders (98 GB+):** Built-in image downscaling and chunked file parsing allow seamless processing of giant local repositories without crashing or freezing.
- **Checkpoint Caching:** Automatically saves index progress every 50 files so long-running folder scans never lose progress.
- **Smart Incremental Updates:** Tracks file modification timestamps (`mtime`) to process only new or modified files on subsequent runs.
- **Embedded Tesseract OCR:** Extracts searchable text from image files automatically without external dependencies.
- **100% Offline & Portable:** Fully self-contained execution on Windows with complete data privacy.
