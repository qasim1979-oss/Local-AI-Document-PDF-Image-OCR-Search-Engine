# Free Standalone Offline Local AI Document, PDF & Image OCR Search Engine (.exe)

A fast, lightweight, and 100% offline Windows desktop application designed to index local folders containing PDFs, Word docs, text files, and images (JPG, PNG, GIF) using integrated Tesseract OCR, TF-IDF vector space matching, and **Smart Incremental Caching**.

## 🚀 Key Features
- **Smart Incremental Caching:** Automatically caches index data on disk to enable lightning-fast sub-second loading on future runs.
- **Delta File Updates:** Detects file modification timestamps (`mtime`) to process only new or changed files.
- **Embedded Tesseract OCR:** Extracts searchable wording from image files automatically.
- **Filename & Content Priority:** Ranks search results by relevance score and exact filename matches.
- **100% Offline & Portable:** Fully self-contained execution with no external cloud or OCR requirements on target PCs.
